# YT-Website-Summarizer

A Streamlit web app that generates detailed summaries of YouTube videos and website content using LangChain and the Llama 3.2 model via the Groq API.

## Features

- Summarize YouTube video titles and descriptions
- Summarize website content
- Clean, user-friendly Streamlit interface
- Uses advanced LLMs for high-quality summaries
- Modular, extensible codebase

## Getting Started
